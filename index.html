How it works

Simple by design.

The SDK manages the Copilot CLI process lifecycle automatically. Your app talks to the SDK; the SDK talks to the CLI over JSON-RPC.

  • Automatic process management The SDK starts, monitors, and stops the CLI process — no shell scripts required.
  • Permission-controlled tools Approve, deny, or customize every tool call through your own permission handler.
  • Bring your own CLI or connect externally Override the bundled binary or point the SDK at an already-running CLI server.

Authentication

Works with how you auth.

Four methods to fit every deployment model — from personal dev tools to production multi-tenant apps.

👤

Signed-in User

Uses stored OAuth credentials from copilot CLI login. Ideal for dev tools.

🔑

OAuth GitHub App

Pass user tokens from your GitHub OAuth app. Great for multi-user SaaS products.

🌿

Environment Variables

COPILOT_GITHUB_TOKEN, GH_TOKEN, or GITHUB_TOKEN. Perfect for CI/CD.

🗝️

BYOK

No GitHub subscription needed. Use your own API keys from OpenAI, Anthropic, or Azure.
